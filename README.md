# To Do List Sorter | [Website]{https://saanviua10.github.io/ToDo-Sort/todoMain.html}

## Program Function

### Tasks
This program is a website that allows the user to input all of their tasks, its due date, the time it is due, and its overall priority. After each task is submitted, the system automatically places the task in a certain position in the list based on the task's due date and priority.

#### Sorting Forumula
The program takes a specific formula to account for the due date and priority when sorting the tasks, ensuring that the individual finishes all tasks on time and ensures that they complete the higher priority tasks sooner.

## Languages and Frameworks Implemented

### Fontend - HTML/CSS
This program uses HTML and CSS for the overall functionality of the frontend as well as the user interface. 

### Middle Connection - JavaScript & API functionality
We used JavaScript and created a local API so that the website saves the user's tasks on their local machine, ensuring that they do not have to type in their tasks every time they open the website.

### Backend - PostgreSQL & Supabase
The program connects to a PostgreSQL database, which is accessed through Supabase, allowing me to scale and see the number of users who are on the website and implementing its system to enhance their day-to-day lifestyle and ensure that all of their tasks are completed in a timely manner.
