# To Do List Sorter

## Program Function

### Tasks
This program is a website that allows the user to input all of their tasks, its due date, the time it is due, and its overall priority. 
After each task is submitted, the system automatically places the task in a certain position in the list based on the task's due date and priority.

#### Sorting Forumula
The program takes a specific formula to account for the due date and priority when sorting the tasks, ensuring that the individual finishes all tasks on time and ensures that they complete the higher priority tasks sooner.
